# Totem Impressão Android V2
Agente Android nativo para impressão automática ESC/POS via Bluetooth.

- Pareamento por código de 6 dígitos gerado no painel.
- Credencial privada criada somente após o pareamento e salva no armazenamento privado do app.
- Impressão Bluetooth RFCOMM direta, sem navegador e sem tela de confirmação.
- Serviço em primeiro plano com retomada após reinicialização.
